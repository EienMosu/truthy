### Task 1: The toolchain and the `:engine` module: a working JDK, pinned versions, the Gradle project, the golden vector loader, the coverage and purity gates, rng, `pad2`, the logo height and the theme rules

Android work cannot start without a JDK that runs, so this task begins there. Spec risk 6 recorded that the JDK bundled with Android Studio (the JBR) hung at launch on this Mac; since 2026-10-15 it starts normally (JBR 25.0.2 in Android Studio 2026.1), so this task uses it through `JAVA_HOME` and only then writes any Gradle file. It then pins every toolchain and library version this plan uses against the release pages and the compatibility tables, and writes them into `gradle/libs.versions.toml` once, so later tasks only reference them.

With a JDK in place it creates the Gradle project `android/Truthy` with its first module, `:engine`: a plain Kotlin JVM module that every later engine task (2 to 6) fills. It holds the content and play types that deck files and progress decode into (`src/content/schema.ts`, `src/content/play.ts`), the seeded generator and the shuffle (`src/engine/rng.ts`), two JavaScript number operations the later ports need bit for bit (`x >>> 0` and `Math.round`), and three small helpers: `pad2` (`components/format.ts`), the logo mark's height (`components/Logo.tsx:20`) and the theme rules (`src/app-state/theme.ts`).

The test source set gets the machinery tasks 2 to 6 use for every golden vector: a loader for plan A's format (card table, `$card`, `$deck`, `$rng`, `$number`, `$undefined`, `$throws`), a coverage test that reads which golden files the suite consumes and checks they exist and are well formed, and a purity test that fails when engine sources reach for a clock, randomness, a timer or coroutine, storage, or an Android or UI import (spec 4.2, as `tests/purity.test.ts` does for the web). The loader lives in the tests, not in the engine: the engine never reads a file. Everything mirrors plan B's task 1 (`docs/superpowers/plans/2026-10-15-truthy-native-b-ios/01-engine-package.md`): the same golden test shapes, the same case loops, the same counts of what is pinned.

**Rules:**

1. **The JDK.** Android Studio's bundled JBR, through `JAVA_HOME` exported in every shell that runs Gradle (README global constraint); no path in any repository file and no change to the owner's shell profile. Fallback: if `java -version` hangs, stop and, with the owner's approval, install a separate JDK 17 or newer and set `JAVA_HOME="$(/usr/libexec/java_home -v 17+)"` instead.
2. **The project.** Kotlin DSL, a version catalog, `FAIL_ON_PROJECT_REPOS` with Google's repository and Maven Central only. The root build declares the Kotlin JVM and serialization plugins `apply false`; task 7 adds the Android application and Compose compiler plugins from the same catalog. No configuration cache, no toolchain auto-provisioning (no foojay plugin): the JDK of rule 1 runs and compiles everything, and `jvmTarget` 17 with Java compatibility 17 keeps the bytecode loadable on Android.
3. **No path in a committed file.** `engine/build.gradle.kts` computes `native-data` from `rootDir` at build time and passes three system properties to the test JVM: `truthy.golden` (the golden folder, as the README requires), `truthy.decks` (the deck folder) and `truthy.engine` (the module folder, for the source scans). They are also declared as task inputs, with `native-data/manifest.json`, so a changed vector, deck or manifest reruns the tests. `local.properties` stays ignored and is not needed by `:engine`.
4. **Content types.** Property names and order are those of a shipped card (`id, section, text, answer, source, difficulty, appliesTo, conflictGroups`) and of the index (schema.ts:93-125). `passName` is the only optional field: a missing key decodes to `null`, and encoding leaves it out again (kotlinx.serialization does not encode a default value). Decoding is strict: a missing required key, or an unknown key, is a `SerializationException`. `Card` is a data class, so `==` compares every field, but engine code compares cards by `id` (README port traps). Times (`at`, `lastSeenAt`) are `Double` epoch milliseconds. `CardHistory.seen` is a `Long`, because the web keeps any stored safe integer up to 2^53 - 1 and a golden case (`readProgress`, "a seen count of 2^53 - 1 is kept") holds one; the other counts are `Int` (README, Global Constraints). A trap for tasks 4 and 9, not handled here: kotlinx.serialization encodes a `Double` with Kotlin's `toString`, so `1760000000000.0` is written `1.76E12`, while the web writes `1760000000000`; the progress writer must produce the web's text.
5. **Enums.** `Mode` and `Theme` carry `wire`, the TypeScript string, and `@SerialName(wire)` on each entry, so `Mode.CLASSIC.wire == "classic"` and JSON reads and writes `"classic"`.
6. **mulberry32, exactly** (reference 3.1): the seed goes through `jsUint32` (`seed >>> 0`: -1 is 2^32 - 1, 1.9 is 1, 2^32 + 1 is 1, NaN and the infinities 0) and is kept in an `Int`; Kotlin's `Int` `+` and `*` wrap exactly like `>>> 0` and `Math.imul`, `ushr` is `>>>`, and the draw is the final 32 bits read as unsigned (`toLong() and 0xFFFFFFFFL`) divided by 4294967296. Each generator owns its state.
7. **shuffle**: Fisher-Yates from the end, `j = floor(rng() * (i + 1))`, exactly `size - 1` draws and none for 0 or 1 item; the input list is not changed.
8. **`jsRound` is `Math.round`, exactly**: the nearest integer, a half rounding toward +infinity, `-0` for x in [-0.5, -0]. Not `kotlin.math.round` (half to even) and not `roundToInt` (half away from zero). `floor(x + 0.5)` is wrong where `x + 0.5` is not exact (`0.49999999999999994` gives 1 instead of 0; `4503599627370497` gives `4503599627370498`), so the function compares the exact fraction `x - floor(x)` with 0.5. A test pins both values.
9. **`pad2(n)`** is `String(n).padStart(2, "0")`: `n.toString().padStart(2, '0')`, negative numbers unchanged ("-5").
10. **`logoMarkHeight(width)`** is `Math.round(((width * 30) / 44) * 100) / 100` in that order of operations: 44 gives 30, 26 gives 17.73, 20 gives 13.64, 0.33 gives 0.23 (an exact half in hundredths that a half-to-even port gets wrong). The web has no function of that name: the rule sits inside the `LogoMark` component, and the golden file is named after the component.
11. **Theme rules.** `parseTheme` takes the stored string, or `null` when nothing (or no string) is stored, and accepts only `"light"` and `"dark"`. The golden cases whose value is not a JSON string (a number, an object, an array) reach the native function as `null` and expect `null`, as the web gives. `switchTheme(choice, systemDark)` is the web's flip rule as a pure function: the opposite of `resolveTheme(choice, systemDark)`; storing it under `THEME_KEY` and showing it are the app's work (tasks 9 and 11), and the flip happens even when storing fails.
12. **The golden loader** follows plan A's format: `{"$card": id}` is the card of the file's table; `{"$deck": id}` is the `cards` array of `native-data/decks/<id>.json`; `{"$number": "Infinity" | "-Infinity" | "NaN" | "-0"}` is that double; `{"$undefined": true}` drops its key from an object and is JSON null elsewhere (a nullable type decodes it to `null`); `{"$rng": {"seed": n}}` is `createRng(n)`; `{"$rng": {"values": [...]}}` returns the values in order and throws `AssertionError("the rng ran out after <n> values")` when asked for one more; `{"$throws": message}` is read with `throwsMessage`. `card(value)` and `cards(value)` are `decode` with `Card.serializer()` and its list serializer. File names are `<module with "/" as ".">.<function>.json`, with plan A's one exception (plan A task 4 rule 1): the constant `DEAL` of `src/engine/deal` is `src.engine.deal.DEAL.constant.json`, because `DEAL.json` and the function's `deal.json` are one file on a disk that ignores case. `decode` runs kotlinx.serialization over the resolved tree with `allowSpecialFloatingPointValues`, so the non-finite numbers survive, `-0` keeps its sign and every finite double comes back bit for bit (checked with `0.30000000000000004`).
13. **Coverage.** `GoldenCoverageTest` reads every `.kt` file under `engine/src/test/kotlin` and collects each `Golden.load` call with two string literals. Five checks: every golden file is well formed (format 1, its name is `fileName(module, function)`, at least one case, unique case names, every card table entry decodes as `Card` with its own id, every `$card` in a case is in the table); every file the suite loads exists; and, once `EVERY_FILE_REQUIRED` is true (task 6), every golden file is loaded by some test. Until then the third check is skipped (JUnit `assumeTrue`) and Gradle lists it as `SKIPPED`. The fourth fails on a `Golden.load(` call in a test source that is not two string literals, because such a call would be invisible to the scan and its file would count as untested. The fifth fails when two golden file names are equal ignoring case.
14. **Purity.** `PurityTest` scans every `.kt` file under `engine/src/main/kotlin/com/eienmosu/truthy/engine` with comments removed (line, block, nested block and KDoc comments; string and character literals stay, as on the web) for: the wall clock (`System.currentTimeMillis`, `java.time`, `java.util.Date` or `Calendar`, `Instant.now`, `Clock.System`, `kotlinx.datetime`), a monotonic clock (`System.nanoTime`, `SystemClock`, `TimeSource`, `measureTime`, `kotlin.time`), randomness (`kotlin.random`, `java.util.Random`, `Random`, `SecureRandom`, `ThreadLocalRandom`, `SplittableRandom`, `.shuffle(`, `.shuffled(`, `.random(`, `UUID.randomUUID`, `Math.random`), a timer, coroutine or scheduler (`kotlinx.coroutines`, `suspend fun`, `delay(`, `Thread`, `Timer`, `TimerTask`, `Handler`, `Looper`, `Executor`, `Executors`, `ScheduledExecutorService`, `Choreographer`), storage (`java.io`, `java.nio`, `File`, `Files`, `Paths`, `SharedPreferences`, `DataStore`, `AtomicFile`, `java.util.prefs`, `okio`) and an Android or UI import (`android.`, `androidx.`, `java.awt.`, `javax.swing.`, `javafx.`). Word boundaries keep the engine's own names clear: `shuffle(items, rng)`, `DeckFile` and task 3's `Clock` data class are not findings. The test also checks that `engine/build.gradle.kts` declares exactly three dependencies, `implementation(libs.kotlinx.serialization.json)`, `testImplementation(libs.junit)` and `testImplementation(libs.kotlin.test.junit)` (the `kotlin.test` assertions that tasks 2 to 6 use, on JUnit 4), and no Android plugin.
15. **Counting tests.** The `:engine` test task prints one line at the end of every run, `Engine tests: <SUCCESS or FAILURE>, <n> run, <n> passed, <n> failed, <n> skipped`, and lists failed and skipped tests by name. The counts in this task's steps are that line. If Gradle reports `:engine:test UP-TO-DATE` (nothing changed since the last run), add `--rerun` to see the line again.

```kotlin
import kotlinx.serialization.SerialName
import kotlinx.serialization.Serializable

/** The class of a round. `wire` is the TypeScript string; the record keys and the progress file use it. */
@Serializable
enum class Mode(val wire: String) {
    @SerialName("classic")
    CLASSIC("classic"),

    @SerialName("streak")
    STREAK("streak"),

    @SerialName("lives")
    LIVES("lives"),

    @SerialName("timed")
    TIMED("timed"),
}

    val lastCorrect: Boolean,

)

    val at: Double,

    val route: Route,
    /** The number the class's record keeps. */
    val score: Int,
    /** Cards answered. */
    val total: Int,
```

```kotlin
// JavaScript number operations the TypeScript engine relies on, written out so the port gives the same bits.
// Internal: the engine files use them, and the tests of this module reach them directly.
package com.eienmosu.truthy.engine

import kotlin.math.floor
import kotlin.math.truncate

private const val TWO_TO_THE_32 = 4294967296.0

/** `x >>> 0`: ToUint32, as a Long from 0 to 2^32 - 1. Truncates toward zero and wraps; NaN and the infinities give 0. */
internal fun jsUint32(x: Double): Long {
    if (!x.isFinite()) return 0L
    val wrapped = truncate(x) % TWO_TO_THE_32
    return (if (wrapped < 0) wrapped + TWO_TO_THE_32 else wrapped).toLong()
}

/**
 * `Math.round(x)`: the nearest integer, a half rounding toward +infinity, -0 for x in [-0.5, -0].
 * Not `kotlin.math.round` (half to even) and not `roundToInt` (half away from zero). `floor(x + 0.5)` is wrong
 * where x + 0.5 is not exact (0.49999999999999994, odd numbers above 2^52); the fraction `x - floor(x)` is
 * always exact, so the comparison is too.
 */
internal fun jsRound(x: Double): Double {
    if (!x.isFinite()) return x
    val down = floor(x)
    val result = if (x - down >= 0.5) down + 1.0 else down
    return if (result == 0.0 && x.toRawBits() < 0L) -0.0 else result
}
```

```kotlin
// Seeded randomness for the engine (src/engine/rng.ts). The engine never draws from the system: a round gets
// one generator from its seed, so the same seed and the same events always give the same round on every platform.
package com.eienmosu.truthy.engine

import kotlin.math.floor

/** Uniform in [0, 1). */
typealias Rng = () -> Double

/**
 * mulberry32. The seed is taken as an unsigned 32-bit integer (`seed >>> 0`): -1 is 2^32 - 1, 1.9 is 1,
 * 2^32 + 1 is 1. The state lives in an Int: Kotlin's Int `+` and `*` wrap like `>>> 0` and `Math.imul`,
 * `ushr` is `>>>`, and the draw reads the final 32 bits as unsigned.
 */
fun createRng(seed: Double): Rng {
    var state = jsUint32(seed).toInt()
    return {
        state += 0x6d2b79f5
        var t = state
        t = (t xor (t ushr 15)) * (t or 1)
        t = t xor (t + (t xor (t ushr 7)) * (t or 61))
        ((t xor (t ushr 14)).toLong() and 0xFFFFFFFFL).toDouble() / 4294967296.0
    }
}

/** Fisher-Yates from the end. Returns a new list; draws exactly items.size - 1 numbers (none for 0 or 1 item). */
fun <T> shuffle(items: List<T>, rng: Rng): List<T> {
    val result = items.toMutableList()
    var i = result.size - 1
    while (i > 0) {
        val j = floor(rng() * (i + 1)).toInt()
        val held = result[i]
        result[i] = result[j]
        result[j] = held
        i--
    }
    return result
}
```

```kotlin
// Reads native-data/golden, the vectors plan A computes by running the TypeScript code. The format is plan A's
// "The golden vector format": one file per function or constant, a card table, tagged values. Test support
// only: the engine itself never reads a file.
package com.eienmosu.truthy.engine

import java.io.File
import kotlinx.serialization.DeserializationStrategy
import kotlinx.serialization.builtins.ListSerializer
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonNull
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.JsonPrimitive
import kotlinx.serialization.json.double
import kotlinx.serialization.json.int
import kotlinx.serialization.json.jsonArray
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive
import kotlinx.serialization.serializer

class GoldenException(message: String) : Exception(message)

/** The tag keys of plan A's format. Kotlin reads `$card` in a string as a template, hence the escapes. */
const val CARD_TAG = "\$card"
const val DECK_TAG = "\$deck"
const val RNG_TAG = "\$rng"
const val NUMBER_TAG = "\$number"
const val UNDEFINED_TAG = "\$undefined"
const val THROWS_TAG = "\$throws"

/** The single key of an object such as {"$card": "id"}, with its value, or null for anything else. */
fun tagOf(value: JsonElement): Pair<String, JsonElement>? {
    if (value !is JsonObject || value.size != 1) return null
    val (key, inner) = value.entries.first()
    return if (key.startsWith("$")) key to inner else null
}

private fun stringOf(value: JsonElement): String? = (value as? JsonPrimitive)?.takeIf { it.isString }?.content

class GoldenCase(val name: String, val input: JsonElement, val output: JsonElement) {
    /** The message of an output written as {"$throws": message}, or null when the case returns a value. */
    val throwsMessage: String?
        get() = tagOf(output)?.takeIf { it.first == THROWS_TAG }?.let { stringOf(it.second) }

    /** The member `key` of the input object, or null when the input has no such key. */
    fun arg(key: String): JsonElement? = (input as? JsonObject)?.get(key)
}

class GoldenFile(
    val format: Int,
    val module: String,
    val function: String,
    val source: String,
    val tests: List<String>,
    val cards: Map<String, JsonElement>,
    val cases: List<GoldenCase>,
) {
    /**
     * `value` with its tags resolved: {"$card": id} becomes the card of the table, {"$deck": id} the cards of
     * native-data/decks/<id>.json (read from `decks`), {"$number": ...} the double it names, and
     * {"$undefined": true} is left out of an object (JSON null anywhere else). {"$rng": ...} and {"$throws": ...} stay.
     */
    fun resolved(value: JsonElement, decks: File = Golden.decksDirectory): JsonElement {
        val tag = tagOf(value)
        if (tag != null) {
            val (key, inner) = tag
            return when (key) {
                CARD_TAG -> {
                    val id = stringOf(inner) ?: throw GoldenException("malformed $CARD_TAG tag: $inner")
                    resolved(cards[id] ?: throw GoldenException("card \"$id\" is not in the file's card table"), decks)
                }
                DECK_TAG -> {
                    val id = stringOf(inner) ?: throw GoldenException("malformed $DECK_TAG tag: $inner")
                    Golden.json.parseToJsonElement(decks.resolve("$id.json").readText()).jsonObject["cards"]
                        ?: throw GoldenException("deck $id has no cards")
                }
                NUMBER_TAG -> when (stringOf(inner)) {
                    "Infinity" -> JsonPrimitive(Double.POSITIVE_INFINITY)
                    "-Infinity" -> JsonPrimitive(Double.NEGATIVE_INFINITY)
                    "NaN" -> JsonPrimitive(Double.NaN)
                    "-0" -> JsonPrimitive(-0.0)
                    else -> throw GoldenException("malformed $NUMBER_TAG tag: $inner")
                }
                UNDEFINED_TAG -> JsonNull
                else -> value
            }
        }
        return when (value) {
            is JsonArray -> JsonArray(value.map { resolved(it, decks) })
            is JsonObject -> JsonObject(value.filterValues { !Golden.isUndefined(it) }.mapValues { resolved(it.value, decks) })
            else -> value
        }
    }

    /** `value`, resolved, decoded with `deserializer`. Infinity, NaN and -0 survive (allowSpecialFloatingPointValues). */
    fun <T> decode(deserializer: DeserializationStrategy<T>, value: JsonElement, decks: File = Golden.decksDirectory): T =
        Golden.json.decodeFromJsonElement(deserializer, resolved(value, decks))

    inline fun <reified T> decode(value: JsonElement, decks: File = Golden.decksDirectory): T = decode(serializer<T>(), value, decks)

    /** One card: a {"$card": id} reference or a card object. */
    fun card(value: JsonElement, decks: File = Golden.decksDirectory): Card = decode(Card.serializer(), value, decks)

    /** A list of cards: an array of references or cards, or {"$deck": id}. */
    fun cards(value: JsonElement, decks: File = Golden.decksDirectory): List<Card> =
        decode(ListSerializer(Card.serializer()), value, decks)

    /**
     * The generator an rng argument stands for: {"$rng": {"seed": n}} is createRng(n); {"$rng": {"values": [...]}}
     * returns the values in order and fails the test when they run out.
     */
    fun rng(value: JsonElement): Rng {
        val tag = tagOf(value)
        if (tag == null || tag.first != RNG_TAG) throw GoldenException("not an rng argument: $value")
        val spec = tag.second as? JsonObject ?: throw GoldenException("not an rng argument: $value")
        val seed = spec["seed"]
        if (seed != null) return createRng(seed.jsonPrimitive.double)
        val values = (spec["values"] as? JsonArray)?.map { it.jsonPrimitive.double }
            ?: throw GoldenException("not an rng argument: $value")
        var next = 0
        return {
            if (next >= values.size) throw AssertionError("the rng ran out after ${values.size} values")
            values[next++]
        }
    }
}

object Golden {
    /** Set by the :engine test task from the project directory (engine/build.gradle.kts). */
    private fun property(name: String): File =
        File(System.getProperty(name) ?: throw GoldenException("system property $name is not set: run the tests through Gradle"))

    val directory: File by lazy { property("truthy.golden") }
    val decksDirectory: File by lazy { property("truthy.decks") }
    val engineDirectory: File by lazy { property("truthy.engine") }
    val sourcesDirectory: File by lazy { engineDirectory.resolve("src/main/kotlin/com/eienmosu/truthy/engine") }
    val testsDirectory: File by lazy { engineDirectory.resolve("src/test/kotlin") }

    val json: Json = Json { allowSpecialFloatingPointValues = true }

    /** Plan A task 4 rule 1: the constant DEAL would share a file with the function deal on a disk that ignores case. */
    private val NAME_EXCEPTIONS = mapOf(("src/engine/deal" to "DEAL") to "src.engine.deal.DEAL.constant.json")

    /** "src/engine/rng" and "createRng" give "src.engine.rng.createRng.json"; DEAL is plan A's one exception. */
    fun fileName(module: String, function: String): String =
        NAME_EXCEPTIONS[module to function] ?: (module.replace('/', '.') + "." + function + ".json")

    /**
     * The vectors of one function or constant. Every test that ports a function calls this with two string
     * literals, so the coverage test can find which files the suite consumes.
     */
    fun load(module: String, function: String): GoldenFile = decodeFile(directory.resolve(fileName(module, function)))

    fun decodeFile(file: File): GoldenFile = parse(file.readText())

    fun parse(text: String): GoldenFile {
        val root = json.parseToJsonElement(text).jsonObject
        fun field(key: String): JsonElement = root[key] ?: throw GoldenException("a golden file has no \"$key\"")
        return GoldenFile(
            format = field("format").jsonPrimitive.int,
            module = field("module").jsonPrimitive.content,
            function = field("function").jsonPrimitive.content,
            source = field("source").jsonPrimitive.content,
            tests = field("tests").jsonArray.map { it.jsonPrimitive.content },
            cards = field("cards").jsonObject.toMap(),
            cases = field("cases").jsonArray.map {
                val case = it.jsonObject
                GoldenCase(
                    name = case["name"]?.jsonPrimitive?.content ?: throw GoldenException("a case has no name"),
                    input = case["input"] ?: throw GoldenException("a case has no input"),
                    output = case["output"] ?: throw GoldenException("a case has no output"),
                )
            },
        )
    }

    /** Every file name in native-data/golden, sorted. */
    fun fileNames(): List<String> =
        (directory.list() ?: throw GoldenException("$directory cannot be read")).filter { it.endsWith(".json") }.sorted()

    fun isUndefined(value: JsonElement): Boolean = tagOf(value)?.first == UNDEFINED_TAG
}
```

```kotlin
// The theme rules of src/app-state/theme.ts. Day ("light") or night ("dark"); by default the system decides.
// A press on the theme switch flips the theme the player sees and stores the result under THEME_KEY, which
// wins over the system from then on. Nothing removes the key: there is no way back to following the system.
package com.eienmosu.truthy.engine

import kotlinx.serialization.SerialName
import kotlinx.serialization.Serializable

@Serializable
enum class Theme(val wire: String) {
    @SerialName("light")
    LIGHT("light"),

    @SerialName("dark")
    DARK("dark"),
}

/** The preference key: SharedPreferences on Android, as localStorage on the web. */
const val THEME_KEY = "truthy.theme"

/** "light" or "dark", or null for anything else (no choice, or a value this build does not know). */
fun parseTheme(value: String?): Theme? =
    when (value) {
        "light" -> Theme.LIGHT
        "dark" -> Theme.DARK
        else -> null
    }

fun oppositeTheme(theme: Theme): Theme = if (theme == Theme.DARK) Theme.LIGHT else Theme.DARK

/** A choice wins over the system setting; without one the system decides. */
fun resolveTheme(choice: Theme?, systemDark: Boolean): Theme = choice ?: if (systemDark) Theme.DARK else Theme.LIGHT

/**
 * The flip rule of the web's switchTheme: the opposite of the theme visible now. The caller shows it and stores
 * it under THEME_KEY; the theme flips on screen even when storing fails.
 */
fun switchTheme(choice: Theme?, systemDark: Boolean): Theme = oppositeTheme(resolveTheme(choice, systemDark))
```

```kotlin
import org.junit.Assert.assertTrue

// Spec 4.2, as tests/purity.test.ts does for the web: the engine reaches for no clock, no randomness, no timer,
// coroutine or scheduler, no file or preference storage and no Android or UI import. Time and seeds always come
// in as arguments. The patterns read the code with its comments removed; string literals stay, as on the web.

private val FORBIDDEN: List<Pair<String, Regex>> = listOf(
    "the wall clock" to Regex("""\bSystem\.currentTimeMillis\b|\bjava\.time\b|\bjava\.util\.(?:Date|Calendar)\b|\bInstant\.now\b|\bClock\.System\b|\bkotlinx\.datetime\b"""),
    "a monotonic clock" to Regex("""\bSystem\.nanoTime\b|\bSystemClock\b|\bTimeSource\b|\bmeasureTime(?:Millis|NanoTime)?\b|\bkotlin\.time\b"""),
    "randomness" to Regex("""\bkotlin\.random\b|\bjava\.util\.Random\b|\b(?:Random|SecureRandom|ThreadLocalRandom|SplittableRandom)\b|\.shuffled?\(|\.random(?:OrNull)?\(|\bUUID\.randomUUID\b|\bMath\.random\b"""),
    "a timer, coroutine or scheduler" to Regex("""\bkotlinx\.coroutines\b|\bsuspend\s+fun\b|\bdelay\(|\b(?:Thread|Timer|TimerTask|Handler|Looper|Executors?|ScheduledExecutorService|Choreographer)\b"""),
    "storage" to Regex("""\bjava\.io\b|\bjava\.nio\b|\b(?:File|Files|Paths|SharedPreferences|DataStore|AtomicFile)\b|\bjava\.util\.prefs\b|\bokio\b"""),
    "an Android or UI import" to Regex("""(?m)^\s*import\s+(?:android|androidx|java\.awt|javax\.swing|javafx)\."""),
)

/** The code without its comments: line comments, block comments (nested, as Kotlin allows) and KDoc. */
internal fun withoutComments(source: String): String {
    val out = StringBuilder()
    var i = 0
    while (i < source.length) {
        val c = source[i]
        when {
            source.startsWith("\"\"\"", i) -> {
                val close = source.indexOf("\"\"\"", i + 3)
                val end = if (close < 0) source.length else close + 3
                out.append(source, i, end)
                i = end
            }
            c == '"' || c == '\'' -> {
                var j = i + 1
                while (j < source.length && source[j] != c && source[j] != '\n') {
                    if (source[j] == '\\') j++
                    j++
                }
                val end = minOf(j + 1, source.length)
                out.append(source, i, end)
                i = end
            }
            source.startsWith("//", i) -> {
                val newline = source.indexOf('\n', i)
                i = if (newline < 0) source.length else newline
            }
            source.startsWith("/*", i) -> {
                var depth = 0
                var j = i
                while (j < source.length) {
                    if (source.startsWith("/*", j)) {
                        depth++
                        j += 2
                    } else if (source.startsWith("*/", j)) {
                        depth--
                        j += 2
                        if (depth == 0) break
                    } else {
                        j++
                    }
                }
                out.append(' ')
                i = j
            }
            else -> {
                out.append(c)
                i++
            }
        }
    }
    return out.toString()
}

internal fun findings(file: String, source: String): List<String> {

    return FORBIDDEN.filter { (_, pattern) -> pattern.containsMatchIn(code) }.map { (name, _) -> "$file uses $name" }
}
```
